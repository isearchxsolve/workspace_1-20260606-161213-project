# Travelling Salesman Problem Solver

This project solves the Travelling Salesman Problem using dynamic programming.

## Usage

1. Run `node tsp.js` to start the program.
2. Enter the number of cities when prompted.
3. Enter the distances between cities when prompted.
4. Enter the cities when prompted.
5. The program will output the solution.

## Algorithm

The algorithm used is a dynamic programming approach. It uses a 2D array to store the minimum distance between each city and the previous city.
